"Automated Smart Locker System: Hardware & Software Integration"


This repository contains a guide on designing, programming and building a smart locker system ,which is controlled by a smartphone via NFC.

You will find files and releases about:

**Microcontroller Code**: A .txt file with the C++ code of the microcontroller. It contains detailed comments in English

**Android App**: The .apk file of the app for those who want to rebuild or study it.

**3D Model**:The .SLDPRT & .STL files of a 3D printed box, used for the protection of the board.

**Video Demonstration**: A link to a short YouTube video providing a presentation of the system and an explanation of the circuit design (https://youtu.be/wcnZShP9BXc).



Developed as a university thesis project for the Department of industrial and Management Engineering at the International Hellenic University (IHU).
