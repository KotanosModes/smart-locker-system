"Automated Smart Locker System: Hardware & Software Integration"


This repository contains an end-to-end guide on designing, programming and building a smart locker system ,which is controlled by a smartphone via NFC.

In particular, the NFC technology and the communication between the microcontroller and the smartphone are explained, such as the PN532 NFC Module.

For this cause, the development of an app was mandatory in order to control the system. To achieve that, Android Studio has been used.

Also, there is a .txt file which contains the full C++ code of the microcontroller with detailed comments, and a realease with an .apk file of the app,for those who want to rebuild or study it.

Moreover, there are files about:

**3D MODEL**:The .SLDPRT & .STL files of a 3D printed box, used for the protection of the board.

**Thesis Document**: The .pdf of my thesis in which everything about the project is explained.

**Video Demonstration**: A link containing a link to a short Youtube video that explains the hardware and presents the final construction
